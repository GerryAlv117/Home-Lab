# Home-Lab
Repositorio dedicado a documentar la construcción, configuración y aprendizaje durante todo el desarrollo de mi propio Home-Lab.

## Objetivo:
el objetivo de este proyecto es crear un entorno de laboratorio en casa que me permita desarrollar conocimientos relacionados con:
- Linux y administracion de servidores
- Redes y servicios de Red
- Ciberseguridad
- Contenedores y Docker
  
## Hardware utilizado
Inspiron 3520
- i3-2370M — 2C/4T
- 6 GB RAM
- SSD 500 GB
- Ethernet cable cat5e 

Ademas de servir como entorno de prácitca, este reporsitorio funcionara como una bitácora técnica, donde documento el avance y sus configuraciones realizadas, problemas encontrados, soluciones y aprendizaje adquirido durante todo el proceso.

## Filosofía del proyecto
Este Home Lab no busca únicamente tener servicios funcionando, sino entender cómo funcionan, configurarlos, documentarlos y aprender de los errores encontrados durante el proceso.

Cada sección de la documentación intentará explicar qué se hizo, por qué se hizo, los comandos utilizados y cualquier problema o solución encontrada.
